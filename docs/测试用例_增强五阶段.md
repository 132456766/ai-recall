## 一、本轮修复的真实缺陷（非增强，是 bug）

### B1 书籍关联断裂（错题卡片书籍徽章不显示 / 编辑丢书）【严重】
- 根因：`bookId` 实际以**顶层字段**存入加密 blob（`db.js` addError），但 `ErrorCard` 误读 `error.source.bookId`（恒为 undefined），`Entry` 编辑载入也读错路径。
- 修复：
  - `ErrorCard.jsx`：`books.find((b) => b.id === error.bookId)`；徽章可点击跳转 `/books`。
  - `Entry.jsx` 编辑载入：`setBookId(data.bookId || '')`。
- 用例：
  - [books.test] 录入含 bookId 的错题，读取后 `bookId` 在顶层且 `source.bookId` 不存在。
  - [books.test] `api.createError` + `api.getError` 能拿到 `bookId`（等价于 ErrorCard 显示所需）。

### B2 相似题 / 变式题恒为通用题【中等】
- 根因：`api.mock.generateQuestion(errorId)` 把入参当 id 去 `db.getError`，但 `Entry` 传 `{knowledgePoints,subject}`、`Review` 传整条 error 对象，导致取不到真实内容、出题永远基于空知识点。
- 修复：`api.mock.generateQuestion` 兼容 id 与对象两种入参。
- 用例：[books.test] 传对象 / 传完整 error / 传 id 三种形态均基于真实知识点出题。

### B3 次要交互缺口【低】
- Help「提交反馈」按钮原为 no-op → 接入 `toast` 反馈提示。
- Chat 无法删除对话 → 新增 `deleteChat` store 动作 + 侧栏每条对话的删除按钮。
- `login` 后补充 `refreshSubjects/refreshKPs/refreshBooks`，确保（真实模式）返回账号的自定义学科/书籍在登录后立即可用。

## 二、本轮补齐的功能闭环

### F1 书籍库管理页（让「添加书籍」形成完整闭环）【新增】
- 背景：store 早有 `updateBook/deleteBook` 却无 UI 使用——用户只能增不能改/删，属未完成功能。
- 新增 `src/pages/Books.jsx`：书籍网格列表，支持**新增 / 编辑 / 删除**；删除前 `confirm` 提示（仅解除关联，保留错题）。
- 接入：`App.jsx` 注册 `/books` 路由；`Sidebar.jsx` 新增「书籍库」入口（BookOpen 图标）；`ErrorCard` 书籍徽章点击直达。
- 用例：[books.test] 新增→编辑→删除 全流程；空书名拒绝新增。
