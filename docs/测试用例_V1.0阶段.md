## 4. 已知限制（V1.0）

- AI 能力仍由前端 Mock 层模拟，按 API 契约封装（`src/services/api.js`），真实后端接入仅需替换该层实现，UI 与存储保持不变。
- 云同步/家长绑定为本地模拟（演示），真实多端同步需接入后端 + 账号体系。
- 商业化（付费转化）在 V2.0 阶段以机构端形式落地。
