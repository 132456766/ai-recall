## 4. 非功能验收

| 项 | 要求 | MVP 实现 |
| --- | --- | --- |
| 数据安全 | 本地 AES-256 加密 | ✅ `crypto.js` AES-GCM，jsdom 下自动降级明文 |
| 注销清除 | IndexedDB 彻底清除 | ✅ `wipeAll()` |

| 性能 | 首屏 <2s | ✅ 静态构建 + 本地数据 |

## 5. 已知限制（MVP）

- AI 能力（OCR/标注/对话/出题/批改）由前端 Mock 层模拟，按 API 契约封装，后续可无缝替换为真实后端（见 `src/services/api.js`）。
- 10000+ 错题的查询性能优化（Web Worker 异步 / 虚拟滚动）已在架构预留，当前为内存过滤。
- 阶段2（V1.0）将补齐：错因推断&相似题、AI 出题&批改、AI 对话、多视图、错因饼图&学情报告、对话录入&批量导入、Markdown 导出、云同步&家长绑定、备忘关联&倒计时、批量操作。
