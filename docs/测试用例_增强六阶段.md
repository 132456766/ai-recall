# AI 错题本 · 增强六阶段测试用例（继续优化：复习结果详细解析 + 搜索二次筛选）

> 目标：在功能已全部可用（增强五）的基础上，继续打磨两项核心体验——
> 1. 复习结果页补上「详细解析」展示缺口（此前详细版仅在 AI 预览里有）；
> 2. AI 搜索结果支持意图维度二次筛选叠加。

---

## 一、本次改动清单

| 文件 | 改动 |
| --- | --- |
| `src/lib/searchFilter.js`（新增） | 纯函数 `filterResults(results, filters)`，支持 学科/掌握度/错因/收藏/难度≥/知识点 六维度叠加过滤，便于单测 |
| `src/pages/Search.jsx` | 意图 chips 改为带维度结构 `{dim,val,label}`；点击 chip 在对应维度叠加/取消前端过滤；结果区显示「已筛选 X / 共 Y」与「清除筛选」；空结果区分「全无匹配」与「筛选后无匹配」 |
| `src/pages/ReviewResult.jsx` | 每条复习结果可点击展开，展示题目全文、参考答案、精简解析、详细解析（analysisDetail）、错因/自评/收藏标签 |
| `src/lib/searchFilter.test.js`（新增） | 9 项二次筛选单测 |

## 二、复习结果详细解析 — 测试用例

| 编号 | 用例 | 操作 | 预期 |
| --- | --- | --- | --- |
| R1 | 结果列表可展开 | 点击任意一条复习结果 | 该行向下展开题目、参考答案、解析区域 |
| R2 | 展示题目全文 | 展开含长题干的错题 | 显示完整 `question`（不再截断 40 字） |

| R5 | 详细解析展示 | 展开 `analysisDetail` 存在的错题 | 出现「▸ 详细解析（AI 版）」可折叠入口，展开后显示详细内容 |
| R6 | 错因标签 | 展开 `errorReason` 存在的错题 | 显示「错因：xxx」徽章 |
| R7 | 自评标签 | 展开已自评的错题 | 显示「自评：已掌握/模糊/未掌握」徽章 |

| R10 | 未掌握题保留入口 | 展开答错的题 | 仍显示「加入复习队列」按钮，点击跳 `/review?error=id` |

## 三、搜索二次筛选 — 测试用例

| 编号 | 用例 | 操作 | 预期 |
| --- | --- | --- | --- |
| S1 | 学科筛选 | 搜索「数学」后点击「学科：数学」chip | 结果仅剩 subject=math 的错题，顶部显示「已筛选 X / 共 Y」 |
| S2 | 掌握度筛选 | 点击「掌握：未掌握」chip | 结果仅剩 masteryStatus=unmastered |
| S3 | 错因筛选 | 点击「错因：计算」chip | 结果仅剩 errorReason=calc |
| S4 | 仅收藏筛选 | 点击「仅收藏」chip | 结果仅剩 favorite=true |
| S5 | 难度阈值 | 点击「难度 ≥ 3」chip | 结果仅剩 difficulty>=3 |
| S6 | 知识点筛选 | 点击「知识点：导数」chip | 结果仅剩 knowledgePoints 含「导数」 |
| S7 | 多维度叠加 | 先点「学科：物理」再点「错因：计算」 | 结果与两条件 AND 一致（物理 且 计算） |
| S8 | 取消某一维度 | 再次点击已激活的 chip | 该维度过滤取消，结果恢复 |
| S9 | 清除全部筛选 | 点击「清除筛选」 | 所有维度清除，恢复 AI 原始结果 |
| S10 | 筛选后无匹配 | 叠加矛盾条件 | 显示「叠加筛选后无匹配错题」+ 清除筛选按钮（不误显示「未找到匹配」） |
| S11 | 时间窗不参与前端过滤 | 点击「时间：本周」chip | 仅高亮提示，不二次过滤（已在查询阶段处理） |

## 六、架构说明

- 二次筛选为纯前端逻辑，不改 `api.js`/`bend.js` 两层门面与契约；真实后端接入方式不变。
- `filterResults` 独立成纯函数，组件与单测共用，便于后续在其它列表（如首页错题流）复用。
