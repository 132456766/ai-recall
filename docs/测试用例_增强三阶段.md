# 测试用例文档 · 增强三阶段（AI 智能搜索）

> 阶段目标：在「录入增强二」基础上，新增 **AI 智能搜索** 能力——用自然语言描述想找的错题，AI 解析意图（学科 / 知识点 / 难度 / 错因 / 掌握度 / 收藏 / 时间），在本地错题库中做结构化检索并排序，同时生成中文检索摘要，并联动相关备忘与书籍。
> 模式：本地优先（mock），`VITE_API_MODE=real` 时由后端 `/api/v1/ai/search` 承接，前端零改动。
> 验证环境：`npm run build` 通过；`npx vitest run` → 67 passed（新增 `src/lib/search.test.js` 12 项）。

## 3. API 契约（对齐 `src/services/contract.js`）

| 方法 | 端点 | 请求 | 响应 data |
| --- | --- | --- | --- |
| `search(query)` | `POST /api/v1/ai/search` | `{ query: string }` | `{ query, intent, results, memos, books, summary, total }` |

- `intent`: `{ subject, kps[], difficulty, errorReason, mastery, favorite, timeRange, freeText }`
- `results`: 匹配的错题对象数组（已解密，含 `masteryStatus`/`knowledgePoints`/`createdAt` 等）
- `summary`: 中文检索摘要（前端直接展示，非存储字段）
- 返回信封统一为 `{ code:200, message, data }`，与现有门面一致。

## 5. 已知限制（增强三）

- AI 意图解析为**本地关键词/规则解析**（Mock），非大语言模型；复杂长句可能拆分不出多重条件（如「上周数学里既未掌握又收藏的难题」会取并集匹配，不保证严格交叠）。
- 真实后端只需实现 `POST /api/v1/ai/search` 返回相同 `data` 结构，前端零改动；语义理解能力取决于后端模型。
- 时间窗口「上周」按「7~13 天前」近似，未做按自然周（周一~周日）切割。
- 相关备忘/书籍仅做标题/内容的关键词包含匹配，未做语义相关度排序。
